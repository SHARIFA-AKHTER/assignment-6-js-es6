# Peddy - Pet Adoption Platform

**Short Description**  
Peddy is a dynamic and responsive web application that allows users to explore and adopt pets. Users can browse different pet categories, view detailed information about each pet, like pets, and adopt their favorite ones.

## Key Features
1. **Dynamic Pet Categories**: Fetch and display pet categories from an API with user-friendly buttons for each category.
2. **Pet Details Modal**: Click on a pet to view detailed information, including breed, date of birth, gender, and vaccination status.
3. **Like & Adopt Functionality**: Users can like their favorite pets and see them in a separate "Liked" section. Adopting a pet shows a congratulations modal.
4. **Smooth Scroll**: Button functionality for smooth scrolling to different sections of the page.
5. **Fallback for Missing Data**: Displays "Not Available" for missing data fields, ensuring a smooth user experience even if some API data is unavailable.

## ES6 Features Used
- **Arrow Functions**: Simplified function expressions.
- **Template Literals**: Used for dynamic HTML content rendering.
- **Destructuring Assignment**: Extracts values from objects for cleaner code.
- **Async/Await**: Handles asynchronous API calls in a readable and maintainable way.
- **Default Parameters**: Fallbacks for missing data with the `||` operator.
